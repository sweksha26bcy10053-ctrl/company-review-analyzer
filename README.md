# Company Review and Complaint Analysis System
 Introduction
   This is a beginner-level Python project for analyzing company reviews and complaints.
   The system takes a company name and a review from the user. It checks the review for positive and negative words,identifies the areas mentioned in the review, and gives suggestions for improvement.

*Features
- Enter a company name and review
- Find positive points in the review
- Find negative points or problems
- Identify areas such as product, delivery, service, price, app and staff
- Give suggestions for improving the identified problems
- Classify the review as Positive, Negative, Mixed or Neutral
- Save reviews in a text file
- View previously saved reviews
  * Python Concepts Used
- Variables
- Strings
- Lists
- Dictionaries
- Input and output
- If-elif-else statements
- For loops
- While loops
- Functions
- File handling
* Requirements
Python 3 or above is required.
No external Python libraries are required.

* How to Run the Project
#Step 1: Download the project
Clone the repository using:
git clone https://github.com/sweksha26bcy10053-ctrl/company-review-analyzer.git
# Step 2: Open the project folder
cd company-review-analyzer
# Step 3: Run the Python program
python main.py
If python does not work, try:
python3 main.py
# How to Use 
After running the program, the following menu will appear:
1. Analyze Review
2. View Saved Reviews
3. Exit
Choose option 1 to enter a company name and review.
The system will display:
- Overall result
- Good points
- Problems
- Areas identified
- Suggestions
The review is then saved in reviews.txt.
Choose option 2 to view previously saved reviews.
Choose option 3 to exit the program.
